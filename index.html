Run it on another computer

  1. Unzip Grain_yantra_1.zip.
  2. Windows: double-click Run_Grain_yantra_1.bat. macOS / Linux: run ./Run_Grain_yantra_1.sh.
  3. The software opens in its own window, or in your browser if the optional pywebview package is not installed.
